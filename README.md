## Distance Calculator
A lightweight Python script that calculates the straight-line distance between two points in a 2D coordinate system using the Pythagorean theorem.
## Description
This program takes the X and Y coordinates of two distinct points in a Cartesian plane and computes the precise Euclidean distance between them. It is designed for quick geometric calculations via the command line.
## Input Needed
The program requires four numerical inputs provided sequentially via the terminal prompt:

* Point 1: X-coordinate (x1) and Y-coordinate (y1)
* Point 2: X-coordinate (x2) and Y-coordinate (y2)

Inputs can be integers or floating-point numbers.
## How to Run the Program
   1. Ensure you have Python 3.x installed on your system.
   2. Open your terminal or command prompt.
   3. Navigate to the directory containing the file.
   4. Run the script using the following command:
   python distance_calculator.py
